# Сложно сосредоточиться

Адаптивная страница о концентрации внимания. Проектная работа Яндекс Практикума.

## Возможности

- Светлая и тёмная темы, автоматический выбор по настройкам системы.
- Сохранение выбранной темы между посещениями.
- Адаптивная сетка для телефона, планшета и компьютера.
- Управление с клавиатуры, видимый фокус и описания изображений.

## Запуск

Откройте `index.html` в браузере. Для локального сервера можно выполнить
`python -m http.server 8000` в папке проекта и открыть http://localhost:8000.

## Технологии

HTML, CSS Grid, Flexbox, CSS-переменные, медиазапросы и JavaScript из стартового шаблона.
